**Autorzy:** Kaxus oraz Marcin „AI Pacino”

Dziękujemy za pobranie naszego spolszczenia!

Jest to drugie spolszczenie przygotowane wspólnie z Marcinem „AI Pacino”. Projekt powstał z pasji do serii *The Legend of Zelda* oraz chęci umożliwienia polskim graczom poznania całej historii Skyward Sword w rodzimym języku.

## Instalacja

Do instalacji potrzebujesz **własnej, czystej kopii gry The Legend of Zelda: Skyward Sword w wersji USA w formacie WBFS lub ISO. Nie używaj wersji europejskiej, japońskiej ani żadnej innej.

### 1. Wypakuj obraz gry

Wypakuj oryginalny obraz gry do osobnego folderu. Po wypakowaniu powinien znajdować się w nim folder `DATA`.

Do wypakowania możesz użyć:

- **Dolphin Emulator** – umożliwia przeglądanie systemu plików gry i wypakowanie plików przez okno **Properties → Filesystem**.
- **Wiimms ISO Tools (wit)** – narzędzie dla Windows, macOS i Linux, które potrafi wypakować obraz WBFS/ISO do folderu i później utworzyć z niego nowy plik WBFS.

> Dolphin jest wygodny do podejrzenia i wypakowania plików, ale do utworzenia nowego pliku WBFS po modyfikacji użyj Wiimms ISO Tools.

### 2. Skopiuj pliki spolszczenia

1. Otwórz folder `DATA` znajdujący się w pobranym archiwum ze spolszczeniem.
2. Otwórz folder `DATA` w wypakowanej, oryginalnej wersji USA gry.
3. **Skopiuj zawartość** folderu `DATA` ze spolszczenia do folderu `DATA` oryginalnej gry.
4. Gdy system zapyta, wybierz **zastąpienie istniejących plików**.

### 3. Spakuj grę z powrotem do WBFS

Ciesz się graniem po polsku :)



### macOS: WITGUI

Na macOS możesz przeprowadzić cały proces w **WITGUI** — graficznej nakładce na Wiimms ISO Tools.

1. Dodaj do biblioteki WITGUI swoją czystą wersję USA gry (`.wbfs` lub `.iso`).
2. Użyj opcji **Export** i wypakuj grę do osobnego folderu. W wypakowanym folderze znajduje się `DATA`.
3. W Finderze przejdź do `DATA` w wypakowanej grze i skopiuj tam **zawartość** folderu `DATA` ze spolszczenia. Wybierz **Zastąp**, gdy Finder o to zapyta.
4. Wróć do WITGUI, wybierz zmodyfikowany folder gry i ponownie użyj **Export**. Jako format wynikowy wybierz **WBFS** (albo **ISO**, jeśli tego potrzebujesz).
5. Wskaż miejsce zapisu i poczekaj na zakończenie eksportu. Powstanie gotowy, spolszczony plik gry.

## Ważne

- Spolszczenie działa **wyłącznie z amerykańską wersją gry (USA)**.
- Archiwum nie zawiera pełnego obrazu gry ani żadnych danych oryginalnej gry.
- Przed kopiowaniem plików warto zachować kopię czystego, wypakowanego folderu gry.

### Weryfikacja właściwego pliku ROM

Przed wypakowaniem możesz sprawdzić sumy kontrolne swojej czystej kopii gry. Spolszczenie jest przygotowane dla obrazu o następujących wartościach:

| Suma kontrolna | Wartość |
| --- | --- |
| CRC32 | `4f090549` |
| MD5 | `89387d670395b2a2c32f77f167763115` |
| SHA-1 | `a60435a2f929a0026aa1038aab6197b7a74ad8fd` |

Jeżeli suma nie jest zgodna, używasz innej rewizji, wydania lub zmodyfikowanej kopii gry - instalacja może nie działać poprawnie.

## English

### The Legend of Zelda: Skyward Sword – Polish Translation

**Authors:** Kaxus and Marcin “AI Pacino”

This archive contains only the Polish-translation files and the modifications required for them to work. It does not include the game.

### Important

This translation works **only with the USA version** of *The Legend of Zelda: Skyward Sword*. It is not compatible with European, Japanese, or other regional releases.

### Correct ROM checksums

Verify that your clean game image matches the following checksums before extracting it:

| Checksum | Value |
| --- | --- |
| CRC32 | `4f090549` |
| MD5 | `89387d670395b2a2c32f77f167763115` |
